# Unit 05 – Unsupervised Machine Learning & Ensemble Techniques

Practical exercises covering:

- Missing-value imputation, encoding, scaling, and feature engineering
- K-Means, hierarchical clustering, and DBSCAN
- Cluster visualization and the elbow method
- Dimensionality reduction with PCA and t-SNE
- Scikit-learn pipelines, cross-validation, and GridSearchCV
- Ensemble methods: Random Forest, Gradient Boosting, and Voting
