# Unit 04 – Supervised Machine Learning

Practical exercises covering:

- Preparing features and targets for regression and classification
- Splitting data into training and test sets
- Linear and polynomial regression
- Regularization with Ridge and Lasso
- Classification with K-Nearest Neighbors, Support Vector Machines, and decision trees
- Random Forest and model comparisons
- Regression and classification evaluation metrics
- Cross-validation, overfitting, and generalization

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook
