# Unit 03 – Exploratory Data Analysis (EDA)

Practical exercises using Riyadh Marathon results, covering:

- Loading datasets and inspecting their structure and data types
- Summary statistics and data-quality checks
- Data cleaning and conversion of numerical values stored as text
- Exploring relationships and interpreting findings
- Preparing features and targets for introductory predictive modelling
- Train/test splits, regression, and classification
- Evaluating predictions and avoiding target leakage

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook
